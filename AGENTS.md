# Agents

This repository uses GitHub Copilot instructions to guide AI agents.

See [.github/copilot-instructions.md](.github/copilot-instructions.md) for the full instructions.

## Hard rules (read before editing)

- **No real customer names.** This repo is public. Never write real customer, client, or employer names (companies, projects, workspace slugs, notebook names) into any tracked file: source, comments, LLM prompts and tool descriptions, tests, docs, or `.github/skills/**/*.md` frontmatter and examples. Use placeholders such as `Acme Corp`, `Northwind`, `Globex`, `example-org`. See "No real customer names" in the Copilot instructions.
- Before finishing, check your diff for names that came from the user's data and replace them.
